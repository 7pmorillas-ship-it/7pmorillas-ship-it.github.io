Política de privacidad

AsistentePablo es una aplicación de uso personal y privado de su único usuario (6pmorillas@gmail.com).

Los datos de Google Calendar, Gmail y Google Tasks se usan únicamente para prestar las funciones del asistente a su propietario. No se venden, no se comparten con terceros y no se usan para publicidad. Se almacenan solo en el equipo del propietario.

El uso de la información recibida de las APIs de Google cumple la Google API Services User Data Policy, incluidos los requisitos de uso limitado.
